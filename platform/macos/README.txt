ReClaw for macOS (Apple Silicon)

1. Unzip and move ReClaw.app to Applications (or anywhere).
2. The app is not signed with an Apple developer certificate: the first time,
   right-click ReClaw.app > Open > Open. If macOS still refuses, run in Terminal:
       xattr -cr /Applications/ReClaw.app
3. The first start creates the folder Documents/ReClaw. Copy CLAW.REZ (and
   CLAW.FEC with the movies) from your own copy of Claw (1997) to
   Documents/ReClaw/data/en/ (English release) or data/pl/ (Polish release).
   The game files are not included.
Saves, settings and reclaw.log are in Documents/ReClaw/save/.

ReClaw na macOS (Apple Silicon)

1. Rozpakuj i przenieś ReClaw.app do Aplikacji.
2. Aplikacja nie jest podpisana certyfikatem Apple: za pierwszym razem kliknij
   ją prawym przyciskiem > Otwórz > Otwórz (albo w Terminalu:
   xattr -cr /Applications/ReClaw.app).
3. Pierwsze uruchomienie tworzy folder Dokumenty/ReClaw. Skopiuj CLAW.REZ (i
   CLAW.FEC z filmami) ze swojej kopii gry do Dokumenty/ReClaw/data/pl/
   (polskie wydanie) lub data/en/ (angielskie). Plików gry nie ma w paczce.
