ReClaw - Linux (x86_64)
=============================================

PL
1. Skopiuj plik CLAW.REZ z własnej płyty z grą do tego folderu
   (obok run.sh). Rozpakowany folder "Assets" też działa.
   Filmy: CLAW.FEC (z folderu MOVIES na płycie) obok CLAW.REZ.
2. Uruchom ./run.sh
Zapisy, ustawienia i log są w tym samym folderze.
Jeśli gra nie startuje, doinstaluj SDL2:
   sudo apt install libsdl2-2.0-0 libsdl2-mixer-2.0-0 libsdl2-image-2.0-0 libsdl2-ttf-2.0-0 libsdl2-gfx-1.0-0

EN
1. Copy CLAW.REZ from your own copy of the game into this folder (next to
   run.sh). An unpacked "Assets" folder works too. Cutscenes: CLAW.FEC.
2. Run ./run.sh
Saves, settings and the log stay in this folder.

Sterowanie / controls: Options > Controls in the game.
The package contains no game data.
