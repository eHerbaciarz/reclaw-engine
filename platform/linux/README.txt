ReClaw - Linux (x86_64)
=============================================

PL
1. Skopiuj plik CLAW.REZ z własnej płyty z grą do folderu data/pl/
   (polskie wydanie) lub data/en/ (angielskie). Oba = wybór w Opcje > Język.
   Rozpakowany folder "Assets" też działa. Filmy: CLAW.FEC do tego samego folderu.
2. Uruchom ./run.sh
Ustawienia (config.xml), zapisy i rekordy są w folderze save/,
napisy i tłumaczenia w lang/, własne poziomy w custom/.
Jeśli gra nie startuje, doinstaluj SDL2:
   sudo apt install libsdl2-2.0-0 libsdl2-mixer-2.0-0 libsdl2-image-2.0-0 libsdl2-ttf-2.0-0 libsdl2-gfx-1.0-0

EN
1. Copy CLAW.REZ from your own copy of the game to data/en/ (English
   release) or data/pl/ (Polish). Both = choice in Options > Language.
   An unpacked "Assets" folder works too. Cutscenes: CLAW.FEC into the same folder.
2. Run ./run.sh
Settings (config.xml), saves and records are in save/, subtitles and
translations in lang/, custom levels in custom/.

Sterowanie / controls: Options > Controls in the game.
The package contains no game data.
