ReClaw - Windows (64-bit)
===============================================

PL
1. Skopiuj plik CLAW.REZ z własnej płyty z grą do folderu data/.
   Rozpakowany folder "Assets" też działa. Filmy: CLAW.FEC też do data/.
2. Uruchom ReClaw.exe
Ustawienia (config.xml), zapisy i rekordy są w folderze save/,
napisy i tłumaczenia w lang/, własne poziomy w custom/.

EN
1. Copy CLAW.REZ from your own copy of the game to the data/ folder.
   An unpacked "Assets" folder works too. Cutscenes: CLAW.FEC into data/ too.
2. Run ReClaw.exe
Settings (config.xml), saves and records are in save/, subtitles and
translations in lang/, custom levels in custom/.

Sterowanie / controls: Options > Controls in the game.
The package contains no game data.
