Kapitan Pazur / Captain Claw - Windows (64-bit)
===============================================

PL
1. Skopiuj plik CLAW.REZ z własnej płyty z grą do tego folderu (obok Claw.exe).
   Rozpakowany folder "Assets" też działa. Filmy: CLAW.FEC obok CLAW.REZ.
2. Uruchom Claw.exe.
Zapisy, ustawienia (config.xml) i log są w tym samym folderze.

EN
1. Copy CLAW.REZ from your own copy of the game into this folder (next to
   Claw.exe). An unpacked "Assets" folder works too. Cutscenes: CLAW.FEC.
2. Run Claw.exe.
Saves, settings (config.xml) and the log stay in this folder.

Sterowanie / controls: Options > Controls in the game.
The package contains no game data.
