ReClaw - Steam Deck
Unofficial fan-made engine for Claw (1997); not affiliated with Monolith or Warner Bros.
The package contains no game data.

PL
1. W trybie pulpitu rozpakuj folder ReClaw, np. do /home/deck/Games/ReClaw.
2. Skopiuj CLAW.REZ (i CLAW.FEC z filmami) z własnej kopii gry do
   data/pl/ (polskie wydanie) lub data/en/ (angielskie).
3. Steam > Dodaj grę > Dodaj grę spoza Steam > Przeglądaj, typ plików
   "Wszystkie pliki", wybierz ReClaw.sh.
4. Wróć do trybu gry i uruchom ReClaw z biblioteki (zakładka Spoza Steam).
   Układ sterowania w Steam: "Gamepad" (domyślny).
Gra działa na pełnym ekranie 1280x800 (obraz 768x480 skalowany 5/3).
Ustawienia, zapisy i dziennik (reclaw.log) są w folderze save/.

EN
1. In Desktop Mode extract the ReClaw folder, e.g. to /home/deck/Games/ReClaw.
2. Copy CLAW.REZ (and CLAW.FEC with the movies) from your own copy of the
   game to data/en/ (English release) or data/pl/ (Polish).
3. Steam > Add a Game > Add a Non-Steam Game > Browse, file type
   "All Files", choose ReClaw.sh.
4. Back in Gaming Mode start ReClaw from the library (Non-Steam tab).
   Steam controller layout: "Gamepad" (the default).
Full screen 1280x800 (768x480 picture scaled by 5/3).
Settings, saves and the log (reclaw.log) are in save/.

Sterowanie / controls (Opcje > Sterowanie / Options > Controls):
  A skok / jump      B strzał / shoot      X miecz / sword    Y podnieś / lift
  L1 zmiana broni / change weapon          Menu pauza / pause  View mapa / map
