## ReClaw (PortMaster)

Unofficial fan-made engine for Claw (1997); not affiliated with Monolith or
Warner Bros. The package contains no game data.

### PL
1. Rozpakuj `reclaw-portmaster.zip` do folderu `ports/` na karcie (powstanie
   `ReClaw.sh` i folder `reclaw/`), albo zainstaluj przez PortMaster.
2. Skopiuj `CLAW.REZ` (i `CLAW.FEC` z filmami) z własnej kopii gry do
   `ports/reclaw/data/pl/` (polskie wydanie) lub `ports/reclaw/data/en/` (angielskie).
3. Uruchom ReClaw z listy Ports.

Wyjście z gry: Select + Start albo menu pauzy > Wyjście.
Ustawienia, zapisy i dziennik: `ports/reclaw/save/`, wyjście konsoli: `ports/reclaw/log.txt`.

### EN
1. Extract `reclaw-portmaster.zip` into `ports/` on the card (you get
   `ReClaw.sh` and the `reclaw/` folder), or install it with PortMaster.
2. Copy `CLAW.REZ` (and `CLAW.FEC` with the movies) from your own copy of the
   game to `ports/reclaw/data/en/` (English release) or `ports/reclaw/data/pl/` (Polish).
3. Start ReClaw from the Ports list.

Quit: Select + Start or the pause menu. Settings, saves and the log are in
`ports/reclaw/save/`, the console output in `ports/reclaw/log.txt`.

### Controls / Sterowanie
| | |
|---|---|
| D-pad / left stick | move, climb, duck |
| A | jump / skok |
| B | shoot / strzał |
| X | sword / miecz |
| Y | lift, throw / podnieś, rzuć |
| L1 | change weapon / zmiana broni |
| Start | pause / pauza |
| Select | level map / mapa |

The screen: the game renders 480 lines, as wide as the screen (640x480 on 4:3
screens, wider on 16:9), scaled to full screen.
